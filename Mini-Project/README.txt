Electricity Consumption Forecasting Using Machine Learning

1. Install:   pip install -r requirements.txt
2. Train:     python train_model.py      (creates model.pkl and actual_vs_predicted.png)
3. Run app:   python app.py             (open http://127.0.0.1:5000)

To use your own data, replace electricity_data.csv (columns: Date, Temperature, Consumption)
and run train_model.py again.
